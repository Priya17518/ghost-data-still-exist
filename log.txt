# HackerRank Orchestrate October 2026 — Project Brief

## 1. What are we building?

We are solving the HackerRank Orchestrate October 2026 challenge:

“Ghost Data Still Exists”

We are building a read-only AI-powered data deletion compliance investigation agent.

The agent receives a deletion/request case and investigates whether the user's data has actually been removed across the organization's systems.

The agent must determine:

1. What the user is requesting.
2. Whether the request is actually a deletion request.
3. Which internal user identity/entities correspond to the requester.
4. Whether the user's data still exists anywhere.
5. Whether personally identifiable information (PII) is still exposed.
6. Whether active processes can recreate the deleted data.
7. Whether restore/backup mechanisms can recreate the data.
8. Which deletion/retention policy applies to every discovered record.
9. Whether the deletion request is:

   * COMPLETE
   * INCOMPLETE
   * NOT_APPLICABLE
10. What ordered remediation actions are required.
11. What verification must happen after remediation.

## 2. VERY IMPORTANT: The agent is READ-ONLY

The agent must NEVER actually modify company data.

It can:

* investigate
* search
* read evidence
* correlate identities
* reason
* classify
* detect risks
* recommend remediation
* generate verification steps

It must NOT:

* delete records
* update records
* restore backups
* disable pipelines
* modify databases
* modify evidence

For example, the agent may recommend:

DELETE_RECORD

but it must never execute the deletion.

This is a deliberate security architecture.
