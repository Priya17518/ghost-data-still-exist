# Ghost Data Still Exists: Deletion Audit Agent

A deterministic compliance verification engine for GDPR/CCPA personal data erasure requests.

## Deliverables
- `output.csv`: Exactly 518 data rows sorted by `case_id`.
- `code/`: Complete Python audit pipeline.
- `evaluation/`: Contains `evaluation_report.md` and `usage_report.md`.
- `log.txt`: Development chat history and architecture log.
